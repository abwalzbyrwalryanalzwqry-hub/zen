# نسخة Android دون إنترنت

## البناء

```bash
# يحتاج Node 22 وJDK 21 وAndroid SDK 36.
npm run build:apk-web            # المصحف كاملاً مضمَّن تلقائياً
cd android && ./gradlew assembleRelease
```

التوقيع من `android/keystore.properties` (خارج Git). والناتج في `android/app/build/outputs/apk/release/`.

## المصحف

كان المصحف 604 صورة PNG (نحو 73 ميغابايت، و47 بعد ضغطها WebP)، فاحتاج التطبيق نسختين: كاملة
(≈ 50 ميغابايت) وخفيفة تنزّل الصور لاحقاً. استُبدلت الصور بملفات مصحف تطبيق منار:

- `public/data/quran/mushaf15/{page}.json`: تخطيط مصحف المدينة (١٥ سطراً، طبعة V1) لكل صفحة،
  كل سطر بكلماته كما في المطبوع (نحو 4 كيلوبايت للصفحة، 2.4 ميغابايت للمصحف كله). المصدر
  Quran.com برسم مجمع الملك فهد، ويولّده `scripts/build-mushaf15.py` في مستودع منار.
- `public/fonts/kfgqpc-hafs-uthmanic-v18.woff2` (88 كيلوبايت): خط مجمع الملك فهد (حفص)، يوزَّع
  دون تعديل وفق رخصته (`public/fonts/KFGQPC-FONT-LICENSE.txt`).

العرض في `src/components/zen/MushafPage.tsx` والتحميل في `src/lib/mushaf15.ts`. لأنها في `public/`
فهي داخل حزمة التطبيق دائماً، فلم تعد هناك نسخة «خفيفة» ولا تنزيل من الإعدادات.

| النسخة              | الحجم التقريبي | المصحف                  |
| ------------------- | -------------- | ----------------------- |
| قبل (كاملة / خفيفة) | ≈ 50 / 3 م.ب   | صور مضمَّنة / تُنزَّل   |
| الآن                | ≈ 5 ميغابايت   | 604 صفحة مضمَّنة دائماً |

## ما يُخفّض الحجم أيضاً

- **R8** (`minifyEnabled` و`shrinkResources`): يحذف ما لا يُستخدم من كود Java والموارد. قواعد Capacitor مضمَّنة في مكتبته.
- **الخطوط**: WOFF2 بدل OTF، أي ثلث الحجم.
- **لا ملفات ويب**: لا عامل خدمة ولا بيان PWA ولا صفحة عدم اتصال (حُذفت في 6.10).

## الحساب دون اتصال (1.16.0)

الإنترنت يلزم **لتسجيل الدخول وحده**؛ بعده يعمل الحساب كاملاً على الجهاز:

| الطبقة       | الملف                                                                               | ما يفعله                                                                                                                                                   |
| ------------ | ----------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| الجلسة       | `src/lib/offline/stored-session.ts`، `src/hooks/useSession.ts`                      | الجلسة المحفوظة تُعرض في أول رسم، وتبقى إن انتهى رمزها دون اتصال (`offline: true`)، وتُجدَّد عند عودة الاتصال. الخروج يمسح الجلسة ونسخ الجهاز.             |
| التجديد      | `src/lib/offline/auth-offline.ts`                                                   | تجديد الرمز دون اتصال يفشل فوراً بدل 30 ثانية من محاولات auth-js.                                                                                          |
| القراءة      | `src/lib/offline/offline-fetch.ts`                                                  | دوال القراءة (`READ_RPC`) وطلبات GET تُحفظ لكل مستخدم؛ دون اتصال أو برمز منتهٍ تُعاد من الجهاز بلا طلب، وعلى شبكة بطيئة بعد 2.5 ثانية مع تحديث في الخلفية. |
| الاستعلامات  | `src/lib/query-client.ts`                                                           | `networkMode: "offlineFirst"`، ولا إعادة محاولة دون اتصال أو لأخطاء 4xx.                                                                                   |
| السجل اليومي | `src/lib/daily-offline.ts`                                                          | أيام جديدة وحضور وحفظ ومراجعة وملاحظات وإكمال في صناديق إرسال تُرسل بترتيبها.                                                                              |
| التقارير     | `src/lib/reports/offline.ts`                                                        | نسخة تغطي المطلوب + أوراق الجهاز، أو تقرير جزئي مع تنبيه.                                                                                                  |
| غيرها        | `halaqa-register.ts`، `quran/review-outbox.ts`، `memorize-api.ts`، `chat-outbox.ts` | صناديق إرسال سابقة للسجل القديم والمراجعة والحفظ ورسائل المحادثة.                                                                                          |

ما يحتاج الاتصال حتماً: تسجيل الدخول، وإرسال المحادثة واستقبالها، والمساعد وتحليل التلاوة، وإنشاء حسابات الطلاب
والدعوات، والمزامنة والتصدير إلى الخادم. والعميل نفسه (`@supabase/supabase-js`) يُحمَّل بعد الرسم الأول
(`src/integrations/supabase/lazy.ts`)، فالحزمة الأولى 184KB gzip والحد 190.

اختبارات E2E: `e2e/offline-account.spec.ts` (رمز منتهٍ دون اتصال، ويوم جديد يُرسل عند العودة) و«دون اتصال» في
`e2e/reports.spec.ts`. محاكاة الانقطاع في `e2e/offline-net.ts`.

## ميزات الخادم

المساعد وتحليل التلاوة وأدوات المعلّم والإشعارات تمرّ بدوال Supabase Edge (`zen-ai` و`zen-recitation` و`zen-tools` و`zen-push-dispatch`) ، فتعمل في التطبيق مع الاتصال دون أي خادم ويب. لم يعد `VITE_ZEN_SERVER_ORIGIN` مستعملاً (المرحلة 6.5).
