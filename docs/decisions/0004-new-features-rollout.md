# القرار 0004: طرح الميزات الجديدة معطّلة لكل مركز أو خلف مفتاح ميزة

- **التاريخ:** أكتوبر 2026 (خطة التطوير، المراحل 3–5، الإصدارات 1.19.0–1.21.0)
- **الحالة:** معتمد.

## السياق

المراحل 3–5 أضافت ميزات تمسّ الإدارة والمال والمنافسة بين الحلقات: الوضع المبسّط، ودوري الحلقات، وملخص الخميس،
ودفتر الرسوم، والتسميع عن بُعد. ما يناسب مركزاً قد يزعج آخر، والتراجع بإصدار جديد يأخذ أياماً على المتجر.

## القرار

| الميزة                 | التحكّم                                                              | الافتراضي        |
| ---------------------- | -------------------------------------------------------------------- | ---------------- |
| الوضع المبسّط للمعلّم  | تفضيل المستخدم، ويفرضه المركز (`center_simple_mode`)                 | متوقف            |
| دوري الحلقات           | المركز (`centers.halaqa_league_enabled`)، يفعّله المنشئ أو المدير    | معطّل            |
| ملخص الخميس للإدارة    | المركز (`centers.weekly_summary_enabled`)                            | مفعّل            |
| دفتر الرسوم والإيصالات | المركز (`centers.fees_enabled`) + مفتاح الميزة `fees` لمدخل «المزيد» | معطّل لكل مركز   |
| التسميع عن بُعد        | مفتاح الميزة `remote` (مدخلا المعلّم والطالب)                        | ظاهر             |
| قالب القصة للشهادات    | اختيار وليّ الأمر لكل مشاركة، و«إخفاء الاسم الكامل» مفعّل            | الاسم الأول وحده |

- **مفاتيح الميزات** (`src/lib/feature-flags.ts`، `FeatureFlagsCard`) لصاحب التطبيق: إخفاء مدخل أو طرحه لنسبة
  من الحسابات دون إصدار. ليست حماية: الصلاحيات في الدوال وRLS دائماً.
- ما يمسّ المال أو المقارنة بين الحلقات **معطّل حتى يفعّله المركز**، والمشرف لا يرى المبالغ.
- الدوري يرتّب بالتحسّن لا بالقيمة، بلا أسماء طلاب ولا نقاط تُستبدل.
