## ما هو مسموح

- الاستخدام الشخصي والتجاري في التصميم.
- تضمين الخط في التطبيقات والمنتجات البرمجية **كجزء من منتج مُجمّع أو مُعبّأ أو مُعمّى**.
- تضمينه في تطبيقات الجوال المُعبّأة.

## القيود الجوهرية

- يُمنع بيع الخط أو إعادة بيعه أو ترخيصه من الباطن.
- يُمنع إعادة توزيعه أو مشاركته أو رفعه أو استضافته أو إتاحته للتنزيل من أي موقع أو خادم أو منصة رقمية.
- يُمنع تمكين المستخدمين من استخراج الخط أو تنزيله أو إعادة استخدامه كملفات خطوط مستقلة، بما في ذلك عبر تضمين الويب أو التطبيقات.
- يُمنع تعديل الخط أو هندسته عكسيًا أو إنشاء أعمال مشتقة منه.
- يُمنع إزالة أو تغيير إشعارات الحقوق أو العلامات التعريفية.

## القرار التقني لتطبيق زِن

بما أن مستودع `zen` عام، فإن رفع ملفات `.otf` إليه أو نشرها ضمن حزمة الويب العامة قد يتيح تنزيلها أو استخراجها، وهو ما يخالف الترخيص.

لذلك:

- لا تُرفع ملفات الخطوط إلى المستودع العام.
- لا تُنشر ملفات الخطوط في نسخة الويب العامة.
- يُسمح باستخدامها داخل حزمة Android/Capacitor فقط، بشرط أن تبقى جزءًا من الحزمة المُعبّأة وغير قابلة للتنزيل المستقل.
- يجب توفير ملفات الخطوط عبر قناة خاصة أثناء البناء، وليس عبر المستودع العام.

## الخطوط غير المتوفرة

لم تُرفق ملفات **Thmanyah Sans**؛ لذلك لا يتم اعتماده أو إنشاء بديل له باسمه.
